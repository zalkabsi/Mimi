# Mimi

**Every vulnerability report gets a verdict with receipts.**

Mimi helps open-source maintainers triage vulnerability reports. It reproduces a report's claim in isolated sandboxes at the exact affected version and returns an evidence dossier: what was proven, what was contradicted, and how much was tested. It never auto-closes a report; the maintainer decides.

Built for the Nebius x NVIDIA Global AI Hackathon 2026 (Track: Best Apps and Agents), on Nebius Token Factory (Nemotron models and Sandboxes) with Tavily for research.
